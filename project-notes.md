## Project 2: Triage Copilot for Property Managers

**Project type:** B2B AI workflow tool for residential property management

**Description:**
Triage Copilot for Property Managers is a review-first B2B AI workflow tool for U.S. residential property management teams. It converts messy tenant maintenance messages from email, SMS, portal tickets, and call transcripts into structured triage outputs, including urgency, issue category, likely trade, missing information, resident reply drafts, and vendor-ready dispatch summaries.

The MVP was designed and implemented end to end, including the triage pipeline, deterministic safety rules, OpenAI-backed model integration with fallback behavior, persistent ticket and audit storage, a coordinator inbox/work queue, and a human review workspace for editing, approving, or rejecting results. The system prioritizes emergency detection, auditability, structured-output correctness, and human-in-the-loop decision making.

This project demonstrates practical AI product development beyond demos by combining backend engineering, workflow design, safety-conscious LLM integration, and operator-focused UX into a modular, testable, and extensible system.

**What this project demonstrates:**
- B2B workflow and operator-focused product design
- Safety-conscious LLM integration for high-stakes triage
- Deterministic emergency detection and fallback behavior
- Structured output validation and auditability
- Persistent ticket, queue, review, and audit storage
- Human-in-the-loop review, editing, approval, and rejection flows
- Modular backend engineering for an extensible AI workflow product

## Project 3: Customer Support Copilot for Operators

**Project type:** Full-stack internal AI web application for ecommerce support teams

**Description:**
Customer Support Copilot for Operators is an ecommerce support assistant built as a full-stack internal web application for human support agents. The tool analyzes inbound tickets, classifies them into a limited set of supported categories, drafts safe suggested replies, highlights missing information, and recommends whether a case should be escalated while keeping the workflow strictly human-in-the-loop.

The project was designed and implemented end to end, including product spec writing, AI prompt design, structured JSON output contracts, backend validation, fallback handling, local persistence, review history, review-action tracking, sample-ticket QA flows, and an operations-style interface for internal use. The app uses a lightweight stack with vanilla HTML, CSS, and JavaScript on the frontend, Node.js on the backend, Node's built-in HTTP server for API endpoints, SQLite for local persistence, and JSON Schema-based validation for AI outputs.

This project demonstrates practical AI product engineering: translating requirements into a working MVP, building reliable backend flows around LLM outputs, enforcing safe structured responses, handling invalid model output with traceable fallbacks, and improving product quality through automated tests, manual QA support, and iterative UX refinement.

**What this project demonstrates:**
- Full-stack MVP implementation for internal operations teams
- AI prompt design and structured JSON output contracts
- Backend validation, fallback handling, and local persistence
- SQLite-backed review history and review-action tracking
- Human-in-the-loop support workflows with safe suggested replies
- Sample-ticket QA flows, automated tests, and manual QA support
- Lightweight frontend and backend implementation using vanilla JavaScript and Node.js
